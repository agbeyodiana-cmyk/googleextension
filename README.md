Purple Scrimba-style link saver for Vercel.

Deploy as a static site: choose Framework Preset "Other", no build command, and use the project root as the output directory. Keep index.html, index.css, index.js and icon.png together at the root of the repository.

SAVE INPUT saves a typed website. SAVE TAB saves the current website (a normal website cannot read other tabs). DELETE ALL clears saved links. Links are stored in your browser's localStorage.
